使い方

コードトーンを見る

  1. ルート音（C〜B）を選びます。
  2. クオリティ（maj7 / m7 / 7 / m7♭5 / maj / m）を選びます。
  3. 指板に、そのコードの構成音がすべて表示されます。

色は度数を表します。R（琥珀）がルート、3（緑）、 5（青）、7（紫）です。♭3・♭5・♭7 は同じ系統の色でまとめています。 ルートは白い輪で囲って強調しています。

「度数／音名」を切り替えると、ドットの表示が度数から音名に変わります。

押さえ方を見る

「フォーム」に切り替えると、押さえる位置が白い枠で囲まれます。 下のチップ（[C] オープン、[A] 3F など）でポジションを選べます。

枠の下には度数のドットがそのまま残るので、 押さえている各音が和音の何度なのかが同時に分かります。 ミュートする弦には × が付きます。

カポを使う

カポの位置を指定すると、「押さえる形」と「実際に鳴る音」の両方が表示されます。

選ぶのは鳴らしたいコードです。たとえば C を選んでカポ2にすると、 押さえる形は B♭ になり、鳴る音は C のままになります。

音を聴く

指板の任意の位置をタップするとその音が鳴ります。 「コード」ボタンで和音、「アルペジオ」ボタンで1音ずつ順番に鳴らせます。

よくあるご質問

キーを変えてもコードが変わりません

これは仕様です。キーは「その曲で使う音とコードの枠」を示すもので、 選んでいるコード自体は変わりません。

キーを設定すると、ルート選択のボタンに点が付き（キーに含まれる音）、 五度圏の円盤でダイアトニックが明るく表示されます。 いま選んでいるコードがキーの中でどの位置にあるか（Ⅰ・トニックなど）も表示されます。

同じコードなのに押さえ方がいくつも出てきます

ギターでは同じコードを指板上の複数の位置で押さえられます。 CAGED と呼ばれる5つの型（E型・A型・G型・C型・D型）を基準に、 低いポジションから順に並べています。

どれを選んでも鳴る和音は同じです。前後のコードから移動しやすいものを選んでください。

音が鳴りません

端末の消音スイッチ（マナーモード）がオンになっていないかご確認ください。

本アプリは他のアプリの音を止めない設定にしているため、 音楽を再生しながらでもお使いいただけます。

テンションコード（9th や 13th）は使えますか

現在のバージョンでは、maj7 / m7 / 7 / m7♭5 / maj / m の6種類に対応しています。 テンションコードや分数コードは今後のアップデートで検討しています。

変則チューニングには対応していますか

現在は標準チューニング（EADGBE）のみです。

iPadでも使えますか

現在は iPhone 専用です。iPad への対応は今後のバージョンで検討しています。
